## 一、总览

### 1.1 这次改造做了什么

1. **新增 5 个 OpenAI 兼容平台**:`deepseek` / `moonshot`(Kimi) / `glm` / `qwen` / `seedance`。全部是**无状态、APIKey-only**(OAuth 仅保留接口未实现)。其中 Seedance 是视频/图像平台,**只进调度/计费/账号管理,不进 Messages 文本对话路径**(这是全程最容易搞错的非对称点)。
2. **网关派发**:`/v1/messages`(Anthropic 协议入站)在 DeepSeek/Kimi/GLM/Qwen 上走「原生 Anthropic 直转」(forwardAnthropicDirect),按 host 选择官方/中转 URL;`/v1/chat/completions` 与 Responses 路径在国产平台上复用 OpenAI 兼容链路,并处理「非流式上游强制回 SSE」聚合。
3. **计费/定价**:内置国产模型的**人民币官方定价表**(Kimi/DeepSeek/Qwen),按可配置汇率 `cny_to_usd_rate` 折算成美元;新增一张 admin 可配置的**通用模型价格覆盖表**(存 `settings` 表,运行时即时生效,优先级最高)。
4. **前端**:新增 admin「模型定价」覆盖页;让 5 个平台在颜色/图标/徽章/下拉/白名单/Messages 派发配置上正确呈现;用量记录支持 `¥`/`$` 双币种展示。

```go
package service

import (
	"context"
	"errors"
	"strings"
)

var ErrDeepSeekOAuthNotImplemented = errors.New("deepseek OAuth not implemented")

// DeepSeekTokenProvider manages DeepSeek account credentials.
// Currently only API Key mode is supported; OAuth is reserved.
type DeepSeekTokenProvider struct{}

func NewDeepSeekTokenProvider() *DeepSeekTokenProvider {
	return &DeepSeekTokenProvider{}
}

func (p *DeepSeekTokenProvider) GetAccessToken(ctx context.Context, account *Account) (string, error) {
	if account == nil {
		return "", errors.New("account is nil")
	}
	if account.Platform != PlatformDeepSeek {
		return "", errors.New("not a deepseek account")
	}
	if account.Type == AccountTypeAPIKey {
		token := account.GetCredential("api_key")
		if strings.TrimSpace(token) == "" {
			return "", errors.New("api_key not found in credentials")
		}
		return token, nil
	}
	return "", ErrDeepSeekOAuthNotImplemented
}
```

### 3.11 DB 迁移:放宽 platform CHECK(NEW)`backend/migrations/15x_*_user_platform_quota_platform_check.sql`

> **关键背景:platform 名单有三处,必须同时一致** —— ① `service.AllowedQuotaPlatforms`([§3.2](#32-service-层常量别名--配额白名单modifiedbackendinternalservicedomain_constantsgo))、② ent schema 的 CHECK switch([§3.10](#310-ent-schema-check-约束modifiedbackendentschemauser_platform_quotago))、③ **DB migration 里 `user_platform_quotas_platform_check` 的 SQL 白名单**。漏掉第 ③ 处而 ①② 已含某平台时,给该平台配 per-user 配额会出现:ent + service 校验通过、但 `INSERT` 撞 DB CHECK 失败、**功能静默不可用**。
>
> **本仓真实历史**:`150_relax_user_platform_quota_platform_check.sql` 把白名单从 4 个放宽到 **8 个**(anthropic/openai/gemini/antigravity + deepseek/moonshot/glm/seedance),但**漏了后来才加的 `qwen`**。修复 = **新建** `156_add_qwen_user_platform_quota_check.sql`(commit `cb3b80d2`,已发金丝雀对隔离 test 库验证:`schema_migrations` 落记录、约束实测含 qwen),**没有原地改 150**。

**迁移执行机制(理解后才知道为何要新建文件而非改旧的)**:`backend/migrations/migrations.go` 用 `//go:embed *.sql` 自动发现所有 `.sql`,runner(`internal/repository/migrations_runner.go`)按**文件名排序**逐个执行,并在 `schema_migrations(filename, checksum)` 记录。**对已应用的迁移做 sha256 防篡改校验**——改动一条已落库的迁移会让存量库启动直接报错(checksum mismatch)。所以**变更只能新建后续迁移文件**。普通 `.sql` 由 runner 包在事务里执行(并 `SET LOCAL lock_timeout='10s'`);`*_notx.sql` 仅用于 `CREATE/DROP INDEX CONCURRENTLY`。无需任何登记,丢进目录即被发现。

// currentPricingService 让包级 ModelPriceCurrency 也能查覆盖币种（进程内单例）。
var currentPricingService atomic.Pointer[PricingService]

func (s *PricingService) SetSettingRepository(repo SettingRepository) {
	if s == nil { return }
	s.settingRepo = repo
	currentPricingService.Store(s)

// loadOverrides 读取覆盖表，带独立 overrideMu + 60s TTL 进程缓存。
// ⚠️ 绝不能复用 s.mu：GetModelPricing 全程持 s.mu.RLock 并在其中调用本方法，复用会重入死锁。
func (s *PricingService) loadOverrides() []modelPricingOverride {
	if s == nil || s.settingRepo == nil { return nil }
	now := time.Now().UnixNano()

	s.overrideMu.RLock()
	if s.overrideLoadedAt != 0 && now < s.overrideLoadedAt {
		cached := s.overrideCache
		s.overrideMu.RUnlock()
		return cached
	}
	s.overrideMu.RUnlock()

	v, _, _ := s.overrideSF.Do("model_pricing_overrides", func() (interface{}, error) {
		ctx, cancel := context.WithTimeout(context.Background(), 3*time.Second)
		defer cancel()
		raw, err := s.settingRepo.GetValue(ctx, SettingKeyModelPricingOverrides)
		if err != nil && !errors.Is(err, ErrSettingNotFound) {
			// 瞬时故障：保留上一份缓存继续用，5s 短 TTL 后重试，绝不落空表（否则覆盖价静默失效、计费回退低价）。
			s.overrideMu.Lock()
			prev := s.overrideCache
			s.overrideLoadedAt = now + int64(5*time.Second)
			s.overrideMu.Unlock()
			logger.LegacyPrintf("service.pricing", "[Pricing] load model pricing overrides failed, keep previous cache: %v", err)
			return prev, nil
		}
		var list []modelPricingOverride
		if err == nil && strings.TrimSpace(raw) != "" {
			_ = json.Unmarshal([]byte(raw), &list) // NotFound/空串/坏 JSON => 空表
		}
		s.overrideMu.Lock()
		s.overrideCache = list
		s.overrideMatchList = sortedEnabledOverrides(list)
		s.overrideLoadedAt = now + int64(60*time.Second)
		s.overrideMu.Unlock()
		return list, nil
	})
	if list, ok := v.([]modelPricingOverride); ok { return list }
	return nil
}

// sortedEnabledOverrides 返回仅 enabled、按 Model 长度降序的副本（供最长前缀回退）。
func sortedEnabledOverrides(list []modelPricingOverride) []modelPricingOverride {
	out := make([]modelPricingOverride, 0, len(list))
	for _, ov := range list {
		if ov.Enabled && strings.TrimSpace(ov.Model) != "" { out = append(out, ov) }
	}
	sort.SliceStable(out, func(i, j int) bool {
		return len(strings.TrimSpace(out[i].Model)) > len(strings.TrimSpace(out[j].Model))
	})
	return out
}

func (s *PricingService) InvalidateOverrideCache() {
	if s == nil { return }
	s.overrideMu.Lock()
	s.overrideLoadedAt = 0
	s.overrideMu.Unlock()
}

// matchOverride 精确匹配优先，无则最长前缀回退。同时尝试完整名与去 provider 前缀名（lastSegment）。
func (s *PricingService) matchOverride(modelLower string) (modelPricingOverride, bool) {
	if s == nil || s.settingRepo == nil { return modelPricingOverride{}, false }
	s.loadOverrides()
	s.overrideMu.RLock()
	list := s.overrideMatchList
	s.overrideMu.RUnlock()
	if len(list) == 0 { return modelPricingOverride{}, false }

	forms := []string{modelLower}
	if seg := lastSegment(modelLower); seg != modelLower { forms = append(forms, seg) }
	for _, ov := range list { // 精确
		om := strings.ToLower(strings.TrimSpace(ov.Model))
		for _, f := range forms { if om == f { return ov, true } }
	}
	for _, ov := range list { // 最长前缀
		om := strings.ToLower(strings.TrimSpace(ov.Model))
		for _, f := range forms { if strings.HasPrefix(f, om) { return ov, true } }
	}
	return modelPricingOverride{}, false
}

// overrideToLiteLLM 折算成内部“每 token 美元价”：CNY 按运行时汇率，USD 直接用。
func (s *PricingService) overrideToLiteLLM(ov modelPricingOverride) *LiteLLMModelPricing {
	const perToken = 1.0 / 1_000_000.0
	rate := 1.0
	if ov.Currency == CurrencyCNY { rate = s.cnyToUSDRate() }
	p := &LiteLLMModelPricing{LiteLLMProvider: "override", Mode: "chat"}
	p.InputCostPerToken = ov.InputPerM / rate * perToken
	p.OutputCostPerToken = ov.OutputPerM / rate * perToken
	if ov.HasCache {
		p.CacheReadInputTokenCost = ov.CachePerM / rate * perToken
		p.SupportsPromptCaching = true
	}
	return p
}

func (s *PricingService) GetModelPricingOverrides(_ context.Context) (*ModelPricingOverridesDTO, error) {
	list := s.loadOverrides()
	if list == nil { list = []modelPricingOverride{} }
	return &ModelPricingOverridesDTO{Entries: list}, nil
}

func (s *PricingService) UpdateModelPricingOverrides(ctx context.Context, in *ModelPricingOverridesDTO) (*ModelPricingOverridesDTO, error) {
	if s == nil || s.settingRepo == nil { return nil, errors.New("setting repository not initialized") }
	if in == nil { in = &ModelPricingOverridesDTO{} }
	norm := make([]modelPricingOverride, 0, len(in.Entries))
	for _, e := range in.Entries {
		e.Model = strings.TrimSpace(e.Model)
		if e.Model == "" { continue }
		if e.Currency != CurrencyCNY && e.Currency != CurrencyUSD { e.Currency = CurrencyCNY }
		if e.InputPerM < 0 { e.InputPerM = 0 }
		if e.OutputPerM < 0 { e.OutputPerM = 0 }
		if e.CachePerM < 0 { e.CachePerM = 0 }
		norm = append(norm, e)
	}
	b, err := json.Marshal(norm)
	if err != nil { return nil, err }
	if err := s.settingRepo.Set(ctx, SettingKeyModelPricingOverrides, string(b)); err != nil { return nil, err }
	s.InvalidateOverrideCache()
	return &ModelPricingOverridesDTO{Entries: norm}, nil
}

func (s *PricingService) deepSeekPricingOverride(modelLower string) *LiteLLMModelPricing {
	cny, found := matchDeepSeekCNY(modelLower)
	if !found { return nil }

	const perToken = 1.0 / 1_000_000.0
	p := &LiteLLMModelPricing{InputCostPerToken: cny.inputCNY / rate * perToken, OutputCostPerToken: cny.outputCNY / rate * perToken, LiteLLMProvider: "deepseek", Mode: "chat"}
	if cny.hasCache { p.CacheReadInputTokenCost = cny.cacheReadCNY / rate * perToken; p.SupportsPromptCaching = true }
	return p
}

// matchQwenCNY —— 精确优先，再按 coder/flash/turbo/long/max 回退，最后 qwen*/qwq*/qvq* 兜底 qwen-plus
func matchQwenCNY(modelLower string) (cnyModelPricing, bool) {
	m := lastSegment(modelLower)
	if !strings.HasPrefix(m, "qwen") && !strings.HasPrefix(m, "qwq") && !strings.HasPrefix(m, "qvq") {
		return cnyModelPricing{}, false
	}
	if cny, found := qwenPricingTable[m]; found { return cny, true }
	switch {
	case strings.Contains(m, "coder"):
		if strings.Contains(m, "flash") { return qwenPricingTable["qwen3-coder-flash"], true }
		return qwenPricingTable["qwen3-coder-plus"], true
	case strings.Contains(m, "flash"): return qwenPricingTable["qwen-flash"], true
	case strings.Contains(m, "turbo"): return qwenPricingTable["qwen-turbo"], true
	case strings.Contains(m, "long"):  return qwenPricingTable["qwen-long"], true
	case strings.Contains(m, "max"):
		if strings.Contains(m, "qwen3") || strings.Contains(m, "qwen-3") { return qwenPricingTable["qwen3-max"], true }
		return qwenPricingTable["qwen-max"], true
	}
	return qwenPricingTable["qwen-plus"], true
}

func (s *PricingService) qwenPricingOverride(modelLower string) *LiteLLMModelPricing {
	cny, found := matchQwenCNY(modelLower)
	if !found { return nil }
	rate := s.cnyToUSDRate()

	p := &LiteLLMModelPricing{InputCostPerToken: cny.inputCNY / rate * perToken, OutputCostPerToken: cny.outputCNY / rate * perToken, LiteLLMProvider: "dashscope", Mode: "chat"}
	if cny.hasCache { p.CacheReadInputTokenCost = cny.cacheReadCNY / rate * perToken; p.SupportsPromptCaching = true }
	return p
}

// matchByPlatformFallback —— 精确+模糊都没命中时按前缀回退到该平台基础模型定价，避免新模型 $0。
func (s *PricingService) matchByPlatformFallback(model string) *LiteLLMModelPricing {
	type platformRule struct{ prefixes, fallbacks []string }
	rules := []platformRule{
		{prefixes: []string{"deepseek"}, fallbacks: []string{"deepseek-chat", "deepseek-reasoner"}},
		{prefixes: []string{"kimi", "moonshot"}, fallbacks: []string{"kimi-k2.6", "kimi-k2.5"}},
		{prefixes: []string{"glm"}, fallbacks: []string{"glm-5.1"}},
	}
	for _, rule := range rules {
		matched := false
		for _, prefix := range rule.prefixes { if strings.HasPrefix(model, prefix) { matched = true; break } }
		if !matched { continue }
		for _, fb := range rule.fallbacks {
			if pricing, ok := s.pricingData[fb]; ok {
				logger.LegacyPrintf("service.pricing", "[Pricing] Platform fallback matched %s -> %s", model, fb)
				return pricing
			}
		}
	}
	return nil
}

## 八、验证与易错点

### 8.1 编译/生成顺序

1. **ent 代码生成**:改 `backend/ent/schema/user_platform_quota.go` 后必须 `go generate ./...`(或 ent 命令)重生 `backend/ent/userplatformquota/*`,否则 CHECK 放宽不生效。
2. **wire 重新生成**:`ProvidePricingService` 签名加了 `settingRepo`、`NewAdminHandlers` 加了 `modelPricingHandler`——若用 wire codegen,先 `go generate` / `wire` 重新生成 `wire_gen.go` 再 `go build ./...`。**Provider(5 个 TokenProvider)不进 wire**,别误加。
3. 后端 `go build ./...` + `go test ./internal/service/...`;前端 `npm run build`(或 `vue-tsc`)过类型 + `vitest run usagePricing`。

### 8.2 数据库迁移

- **platform 名单三处必须同步**:`AllowedQuotaPlatforms`(service)、ent schema CHECK、**migration SQL 的 `user_platform_quotas_platform_check` 白名单**——漏掉 migration 这处而代码侧已含该平台 = 配额 INSERT 静默失败(本仓 `qwen` 就踩过,见 [§3.11](#311-db-迁移放宽-platform-checknewbackendmigrations15x__user_platform_quota_platform_checksql))。
- migration 新建文件、序号顺延、别撞号;`//go:embed *.sql` 自动发现,无需登记。**绝不原地改已发布的迁移**——runner 对已应用迁移做 sha256 防篡改校验,改了会让存量库启动报错(checksum mismatch);要变更就新建后续迁移(本仓 `156` 即是补 `150` 漏的 qwen)。
- 含 `CREATE/DROP INDEX CONCURRENTLY` 的迁移必须用 `*_notx.sql` 命名(非事务);普通 DDL 走默认事务即可。
- 验证手法(本仓金丝雀已用):部署后进 DB 查 `SELECT * FROM schema_migrations WHERE filename LIKE '15x_%'` 确认落记录,再 `SELECT pg_get_constraintdef(oid) FROM pg_constraint WHERE conname='user_platform_quotas_platform_check'` 确认含全 9 平台。

### 8.3 三层派发名单(最易漏一层)

逐项核对 [§4.11 速查表](#411-派发三层速查对抗漏一层):
- 层① 直转入口(4 家,**无 Seedance**)
- 层② Messages 调度白名单(OpenAI+4,**无 Seedance**;前端 `MESSAGES_DISPATCH_PLATFORMS` 必须一致)
- 层③ 账号调度总名单 `openAICompatPlatforms`(6 家,**含 Seedance**)
- 另需:`resolveTokenProviderForPlatform`(6 家)、`selectAccountForModelWithPlatform`(5 家国产)、三处 `IsOpenAI()→IsOpenAICompatible()`。
- **Seedance 是视频/图像平台,只进调度/计费/账号,不进 Messages 文本路径**——非对称点。

### 8.4 定价与币种口径

- **`model_pricing.json`/`.sha256` 是运行时同步缓存,不可手抄/手改/纳管**(见 [§5.6](#56-数据文件--不要手抄不要纳管))。首次启动 `Initialize()` 自动生成,手改会被 sha256 校验覆盖。
- `GetModelPricing` 里 `matchOverride` **必须在 `s.mu.RLock` 之前**(慢 DB 不能在 RLock 内,否则重入死锁 + 阻塞计费热路径);国产 ¥ 表在 RLock 内;末尾加平台回退。
- `ProvidePricingService` 必须 `SetSettingRepository`(登记 `currentPricingService`),否则 `ModelPriceCurrency` 永远查不到覆盖币种。
- 币种口径:系统 **1¥ = 1 余额单位**(`pricing.cny_to_usd_rate=1.0`),国产模型按官方人民币价存储、前端按 `price_currency` 渲染 `¥`/`$`。若改了汇率,展示需另行换算。

### 8.5 前端易错点

- **国产强制 apikey 模式**(`CreateAccountModal`/`EditAccountModal` 的 `isOAuthFlow`/`watch`)——漏了会让国产平台误入 OAuth 流程。
- **i18n 缺 key**:`nav.modelPricing` + `admin.modelPricing.*`(三个 locale)+ 两处 `platforms` map + 5 个平台账号提示——任一 locale 漏掉会显示原始 key 字符串。
- `ModelPricingView.vue` 的 `handleSave` 的 `Number(x)||0` 兜底必须保留(清空价格框不报 400)。
- `PlatformIcon.vue` 的 moonshot/glm/seedance **非 24x24 viewBox** 不要改。

### 8.6 端到端冒烟

用真实 DeepSeek / Kimi / GLM(官方 + orbitai 中转) / Qwen 账号各打一发:
- `/v1/messages`(流式+非流式)与 `/v1/chat/completions`;
- 重点验:GLM 中转非流式不空响应、Qwen 用 `Bearer`、Kimi 不 403、usage 非零;
- 前端验:创建账号能选到 5 个平台、GLM/Qwen 圆标显示正常、分组页国产平台胶囊配色、deepseek/moonshot/glm/qwen 分组能看到 Messages 调度配置而 **seedance 看不到**、`/admin/model-pricing` 增删行/币种切换/保存/`hasCache=false` 时缓存价禁用。
